# feature/fix_tab: 第１段階の修正

選択中タブの名前や閉じるボタンが消える問題を、Sakura の検証用ブランチで
共有・レビューするためのパッチを保持する。

## 修正する処理

`selected-tab-clip.patch` は darkmodelib の `paintTab()` を修正する。
選択タブの領域を描画対象から除外する前に元のクリップ領域を保存し、
親ウィンドウに各タブの `WM_DRAWITEM` を送る直前に復元する。
これにより、親が選択タブの文字や閉じるボタンを描けるようにする。

対象のサブモジュールコミットは
`ee84dfba4b31dd5d436f29f6c8ad80e8b77a1529`。
適用後の `src/DmlibSubclassControl.cpp` の Git blob は
`28d884851c8e03b1389eefe46298770c439cdb94` で、以前の検証用 EXE に
組み込んでライト表示の改善を確認したソースと一致する。

## ビルド時の流れ

1. 既存の `externals/darkmodelib` からソース・ヘッダー・ライセンスを
   vcpkg のビルド作業フォルダー内のアーカイブへまとめる。
2. vcpkg の標準の展開・パッチ適用処理で、アーカイブのコピーへパッチを適用する。
3. 修正したコピーから `darkmode.lib` をビルドし、Sakura がリンクする。

サブモジュールの URL・参照コミット・作業ファイルは変更しない。
パッチが適用できない場合はビルドをエラーで停止する。
既存のビルド手順が vcpkg のこのポートを使用すれば、手動でパッチを当てる必要はない。
修正前のライブラリと区別するため、ポートは `0.130.0#1` として登録する。

## 確認した範囲（2026-11-07）

元のソースのコピーを使い、CRLF・LF の両方で、ポートのアーカイブ作成と
vcpkg の標準パッチ処理が成功することを確認した。適用後の Git blob は両方とも
上記の検証済みソースと一致し、元のサブモジュールは未変更のままだった。
そのソースとこのポートの `CMakeLists.txt` から Win32 Release の `darkmode.lib`
をビルドした。削除を伴う vcpkg 全体の導入処理、Sakura EXE の再ビルド、
この保持方法による新たな画面確認は未実施。

## レビューと正式対応

実際の描画修正は `selected-tab-clip.patch` を確認する。
`portfile.cmake` とポートの版情報は、修正を検証ブランチでビルドするための変更。
`.gitattributes` は、差分形式の文法上必要な空白を Git の空白エラーから除外する。
第２段階の Sakura 側のタブバー初期化修正は含まない。

本流へ提出する際は、darkmodelib 上流への修正提案と、修正取り込み後の
Sakura のサブモジュール参照・vcpkg 版情報更新を別途整理する。
この検証ブランチのコミット群をそのまま本流へマージする前提ではない。

調査時のスクリーンショット、ビルドログ、詳細な経緯はローカルの
`repro/issue-2804/` に保存している。このフォルダーは Git の除外対象であり、
本 README とパッチを含む通常のソースファイルだけがブランチで共有される。
